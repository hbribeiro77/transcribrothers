# Transcribrothers

Web app para gerar **tutorial em Markdown** a partir de um **vídeo no seu computador** (upload): transcrição com timestamps, capturas de tela e redação via **LiteLLM**.

Instruções de execução e variáveis de ambiente: [repositorio.md](repositorio.md). Resumo do produto: [resumo.md](resumo.md).
